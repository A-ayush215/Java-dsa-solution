# AWS Static Website Hosting

## Objective
Host a simple static website using Amazon S3.

## AWS Services Used
- Amazon S3

## Steps
1. Create an S3 bucket.
2. Upload index.html.
3. Enable Static Website Hosting.
4. Make the bucket publicly accessible.
5. Access the website using the generated S3 website URL.

## Outcome
Successfully demonstrated a basic static website deployment using Amazon S3.
