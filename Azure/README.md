# Microsoft Azure Static Website Hosting

## Objective
Host a simple static website using Microsoft Azure Static Web Apps.

## Azure Services Used
- Microsoft Azure Static Web Apps

## Steps
1. Create an Azure account.
2. Create a Static Web App.
3. Upload the HTML files or connect a GitHub repository.
4. Deploy the website.
5. Access the website using the generated Azure URL.

## Outcome
Created a simple static website project to understand the deployment workflow using Microsoft Azure Static Web Apps.
